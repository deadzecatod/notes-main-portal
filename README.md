# notes-main-portal

## 项目简介

**notes-main-portal** 是一个用于归档和发布多个独立 HTML 页面的仓库。本仓库不针对任何特定域名或网站，仅作为存放各类静态 HTML 文档的集合入口，方便统一维护与版本管理。

## 目录说明

```
.
├── index.html          # 仓库入口页面（导航/索引）
├── pages/              # 存放所有独立 HTML 页面
│   ├── page-a.html
│   ├── page-b.html
│   └── ...
├── assets/             # 公共资源文件夹（CSS、JS、图片等）
│   ├── css/
│   ├── js/
│   └── images/
└── README.md           # 本文件
```

- `index.html`：仓库的主入口页面，通常包含页面列表或链接导航。
- `pages/`：每个独立的 HTML 页面文件存放于此，文件名应具有描述性。
- `assets/`：存放页面共用的样式、脚本和图片资源，便于复用与管理。

## 页面归档说明

本仓库中的每个 HTML 页面均为独立、自包含的文档，可能涉及不同主题、用途或功能。页面之间无强依赖关系，可通过 `index.html` 统一索引访问。

归档原则：
- 每个页面应保持结构清晰，建议包含必要的元数据（如标题、描述）。
- 页面资源尽量引用仓库内 `assets/` 目录下的文件，避免外部链接依赖。
- 如有更新，请直接覆盖对应文件并提交说明。

## 维护说明

- **添加新页面**：将 HTML 文件放入 `pages/` 目录，并在 `index.html` 中添加对应链接。
- **更新页面**：直接修改 `pages/` 下对应文件，提交时注明变更内容。
- **删除页面**：移除文件并更新 `index.html` 中的链接列表，确保索引准确。
- **资源管理**：如需新增公共资源，请放入 `assets/` 对应子目录，并确保引用路径正确。

## 贡献

欢迎提交 Issue 或 Pull Request 以改进页面内容或仓库结构。请确保提交的 HTML 文件符合基本规范，并附带简要说明。
